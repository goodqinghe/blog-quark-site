关于我

26 届本科毕业生，对基础设施、自动化和开源工具感兴趣。

这个博客从最初的 Quarkdown 方案迁移到了 Markdown + Python 轻量构建，整个技术栈的选型和调整过程本身也是学习的一部分。

这个博客在做什么

  • 用标准 Markdown 写文章，YAML front matter 管理元数据
  • Python 脚本自动扫描文章、生成首页、渲染 HTML
  • GitHub Actions 负责 CI/CD：push 到 main 即触发构建
  • 构建产物推送到公开仓库，由 Cloudflare Pages 托管
  • 全部流程自动化，本地只需要写文章和 push
